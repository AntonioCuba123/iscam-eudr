Fórmulas clave — cómo se calculan los índices

// D1-D7: MEDIA GEOMÉTRICA (índice de sostenibilidad — ISCAM) ISA = (D1 × D2 × D3 × D4 × D5 × D6 × D7)^(1/7) // D8-D9: MEDIA ARITMÉTICA (índice de preparación operativa) IP = (D8 × COUNT(D8) + D9 × COUNT(D9)) / (COUNT(D8) + COUNT(D9)) // Vulnerabilidad = complemento del ISA IV = 4 − ISA // Resiliencia = ponderación 70% sostenibilidad, 30% preparación operativa RE = (ISA × 0.7) + (IP × 0.3) // Semáforo: regla de decisión por nivel de riesgo + exposición UE SEMÁFORO = IF(IV ≥ 3, "🔴 ALTO", IF(IV ≥ 2, "🟡 MEDIO", "🟢 BAJO")) // Prioridad EUDR: nivel de riesgo × exporta a UE (multiplicador 2×) PRIORIDAD = IF(AND(NIVEL_RIESGO="ALTO", EXPORTA_UE="SÍ"), "URGENTE", IF(NIVEL_RIESGO="ALTO", "ALTA", IF(NIVEL_RIESGO="MEDIO", "MEDIA", "BAJA")))

Cómo construirlo

Pasos concretos, en orden. Empezamos por el directorio, terminamos en el dashboard.

  1. 1

    Crear Google Sheet vacío

    6 pestañas en blanco. Nombrar las hojas tal como están aquí. Crear las columnas con formato desde el inicio — no agregar columnas después.

    ~15 min
  2. 2

    Subir DIRECTORIO desde CSV

    Exportar EUDRPERU_universo_final.csv → importar a la pestaña DIRECTORIO. Verificar que RUC sea texto (no número) para evitar pérdida de ceros.

    ~10 min · CSV listo
  3. 3

    Configurar validación de datos

    Aplicar listas desplegables a: TIPO_ORG, CADENA, REGION_EUDR, ESTADO_SUNAT, PRIORIDAD_EUDR. Evitar texto libre en estas columnas.

    ~20 min
  4. 4

    Crear SCORECARD con fórmulas

    Agregar RUC desde DIRECTORIO con =UNIQUE(DIRECTORIO!RUC). Escribir fórmulas ISA, IP, IV, RE referenciando INSTRUMENTO2. El semáforo se calcula solo.

    ~30 min
  5. 5

    Armar Google Forms del Instrumento 2

    Crear formulario con las 75 preguntas organizadas por dimensión. Cada pregunta: opción única (0/1/2/3/4). Vincular respuestas a la pestaña INSTRUMENTO2 con Zapier/Make o manualmente.

    ~2-3h · Forms
  6. 6

    Llenar TIMELINE con datos existentes

    Usar la información de FECHA_INSCRIPCION del directorio para crear el primer evento de CONSTITUCIÓN de cada org. Luego agregar certificaciones known.

    ~1h
  7. 7

    Poblar DICCIONARIO

    Copiar la tabla de la Sheet 6 de este documento. Completar quién llena y frecuencia reales.

    ~30 min
  8. 8

    Conectar Looker Studio

    Desde Métricas, "Archivo → Compartir → Publicar en la web" o conectar directamente con Looker Studio para dashboard interactivo.

    ~1h · Looker
  9. 9

    Protocolo de actualización trimestral

    Script Python que re-valida RUCs en SUNAT, cruza con PRODUCE, y genera CSV actualizado. El CSV se vuelve a importar a DIRECTORIO.

    Script Python
